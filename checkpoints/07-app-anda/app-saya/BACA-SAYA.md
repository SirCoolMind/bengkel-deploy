# Letak aplikasi Bengkel Vue anda di sini

1. Di laptop, buka folder projek Bengkel Vue anda (`vue-crud-workshop`).
2. Seret folder `src` ke atas folder `app-saya` ini (di *Explorer* Codespace, sebelah kiri).
3. Dalam *terminal*, taip `npm run app-saya`, tekan **Enter**.

Panduan penuh: `checkpoints/07-app-anda/README.md`
